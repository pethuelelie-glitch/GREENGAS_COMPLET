# lib

- `format.ts` : nombres et unités en français (`1 785`, `8,54 points/kg`, `−30 %`), dates (`12/09/2026 08:30`).
- `libelles.ts` : libellé affiché pour chaque valeur d'énumération (`a_verifier` → « À vérifier », `carton_papier` → « Carton et papier »…).
- `statuts.ts` : correspondance entre une valeur de statut, son jeton de couleur et son icône lucide.
- `config.ts` : lecture des variables `VITE_*`.
