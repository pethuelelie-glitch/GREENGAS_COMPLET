# components

- `ui/` : composants génériques shadcn/ui (bouton, carte, tableau, modale, onglets…), adaptés aux jetons GREENGAS.
- `greengas/` : composants métier partagés entre les rôles : Indicateur, PastilleStatut, BadgeProvenance, LegendeProvenance, CodeObjet, TableauDonnees, JaugeEcart, GraphiqueAttenduMesure, FriseTracabilite, ChampPoids, ModaleConfirmation, PanneauDetail, Bandeau, EtatVide, EtatChargement, EtatErreur.

Un composant utilisé par un seul écran reste dans le dossier `components/` de sa feature.
