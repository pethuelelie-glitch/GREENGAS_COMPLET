# styles

- `tokens.css` : variables CSS des jetons GREENGAS (voir `CLAUDE.md` §6), branchées dans la configuration Tailwind.
- `globals.css` : importe `../assets/fonts/fonts.css` (Inter et JetBrains Mono embarquées, hors ligne), définit les chiffres tabulaires et les styles de base. Georgia est une police système.
