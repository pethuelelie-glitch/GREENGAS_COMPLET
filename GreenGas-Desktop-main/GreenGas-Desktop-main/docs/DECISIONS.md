Chaque décision est numérotée. Pour en changer une, ajouter une nouvelle entrée qui la remplace, plutôt que de modifier l'ancienne.

| D2 | 12/10/2026 | Interface : Tailwind CSS + shadcn/ui, icônes lucide-react, graphiques Recharts. | Composants légers et faciles à aligner sur les maquettes de Claude Design. |
