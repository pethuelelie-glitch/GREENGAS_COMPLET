# Design

- `maquettes/` : captures PNG des écrans **validés** dans Claude Design, nommées avec l'identifiant du brief (`T2-saisie-tri.png`, `M2-site-alerte.png`…).
- `export/` : code ou fichiers exportés de Claude Design (système visuel, composants), qui servent de modèle à Claude Code.

Ne déposer ici que des versions validées. Une maquette remplacée est supprimée, pas gardée à côté.
